# ADR — Architecture Decision Records

## Convention

- Each ADR is a file `NNNN-title.md`, numbered increasingly; never renumber after creation.
- Status: **proposed** → **accepted** → **superseded** (or **rejected**).
- **proposed:** under review, needs owner approval. **accepted:** decided. **superseded:** replaced by a newer ADR. **rejected:** not used.
- Process: write the ADR as proposed → owner decides → update the status. Do not implement a decision while it is still proposed.
- Minimum content: **Context / Decision / Alternatives / Consequences / Open questions**.
